🚀 Getting Started
To get a local copy up and running, follow these simple steps:

Prerequisites
Ensure you have the Flutter SDK installed.

Check your installation by running:

Bash
flutter doctor
Installation
Clone the repository:

Bash
git clone [https://github.com/rengsosubba12-cpu/Quiz_App-AI-.git](https://github.com/rengsosubba12-cpu/Quiz_App-AI-.git)
Navigate to the project directory:

Bash
Cd Quiz_App-AI-
Install dependencies:

Bash
Flutter pub get
Run the app:

Bash
Flutter run
